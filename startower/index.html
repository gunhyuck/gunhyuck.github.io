연결 방법
1. 피클 합동 비서실 DB → 확장 프로그램 → Apps Script
2. Code.gs 전체를 붙여넣고 저장 (시트 ID는 이미 들어 있습니다)
3. 배포 → 새 배포 → 유형 웹 앱, 실행 나, 액세스 모든 사용자 → 배포
4. 나온 /exec 주소를 위에 붙여넣고 저장
※ 카림·스타타워 두 페이지에 같은 주소를 넣으면 됩니다. 주소를 넣기 전에는 이 브라우저에만 저장됩니다.
